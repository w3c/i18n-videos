## Title

翻译文本的字体大小

## Description

```
将文本从一种语言翻译成另一种语言时，长度通常会发生显著变化。例如，简短的英文文本翻译成德语、法语或意大利语时，长度有时会增加 200% 到 300%，而在某些亚洲语言中则会缩短。

沈兆怡（明德国际研究院（MIIS）、W3C国际化工作组特邀专家）通过实际案例分析阐释了“为什么翻译后的文本会破坏页面布局”，大家可以在这个视频中了解到文字大小是如何影响可读性，以及相同内容在不同语言中显示的差异。

关键要点：设计时布局越灵活，就越有利于翻译和国际化。灵活设计您的网页，让文本自然重排，避免使用固定宽度的容器，将内容与呈现方式分离，并提前规划数据库字段。

欢迎进一步阅读文章《文字大小和翻译》了解更多内容：https://www.w3.org/International/articles/article-text-size.zh-hans.html
```
